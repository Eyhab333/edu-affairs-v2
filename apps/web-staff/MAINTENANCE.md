# وضع الصيانة المؤقت

يتم تفعيل صفحة الصيانة لتطبيق بوابة الموظفين فقط من خلال متغير البيئة الخادمي التالي:

```text
MAINTENANCE_MODE=true
```

## التفعيل على Vercel

1. من مشروع Vercel الخاص ببوابة الموظفين، افتح **Settings → Environment Variables**.
2. أضف `MAINTENANCE_MODE` بالقيمة `true` إلى بيئات النشر المطلوبة (عادةً Production، ويمكن إضافته إلى Preview عند الحاجة).
3. أنشئ نشرًا جديدًا من نفس إعدادات البيئة. تغيير المتغير لا يحدّث نشرًا قائمًا تلقائيًا.

## الإيقاف بعد عودة الخدمة

1. احذف المتغير أو غيّر قيمته إلى أي قيمة غير `true`.
2. أنشئ نشرًا جديدًا لتطبيق التغيير.

عند تفعيل المتغير، تعيد `proxy.ts` توجيه طلبات صفحات التطبيق إلى `/maintenance`. تبقى صفحة الصيانة نفسها وملفات Next.js والملفات الثابتة متاحة لتفادي حلقات إعادة التوجيه ومشكلات تحميل الصفحة.

هذا الإجراء يعلّق واجهة الويب فقط؛ لا يعطّل الخدمات الخارجية أو يحمي نقاط النهاية البرمجية بحد ذاته.
